## Baseとの比較

同じ182問で比較すると、v2 SFTはBaseより、指導完了率で23.1ポイント、近接転移正答率で1.7ポイント、共感指導合計で0.813点、数学的指導合計で2.170点、生徒らしさで0.731点低かった。対応比較では、v2 SFTが共感合計で上回った問題は67件、数学指導合計で上回った問題は74件、生徒らしさで上回った問題は49件だった。

一方、平均理解度変化はBaseの+0.484から+0.912へ、平均確信度変化は+0.192から+0.259へ上昇した。直接解答も172回から57回へ減少した。v2 SFTは「答えを直接提示せず対話を続ける」形式を学習したが、その過程で数学的誤りを検出・修正し、生徒の理解を確認して指導を収束させる能力を十分に学習できていない。

## 結論

v2 SFTは直接解答の抑制と、生徒モデル上の理解度・確信度更新には効果が見られる。しかし、共感指導、数学的指導、生徒らしさ、指導完了率、近接転移正答率はBaseを下回った。特に誤答追認、誤り診断、理解確認がボトルネックである。次のSFTでは、単に`Keep`対話を学習するだけでなく、誤答を明示的に検証するCoT、誤りを訂正する教師発話、理解確認から完了判定へ移る正例を増やす必要がある。
