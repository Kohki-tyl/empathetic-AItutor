# ベースライン評価レポート: Swallow-70B (SFT前)

## 1. 評価概要
本レポートは、数学の共感的な対話指導（チュータリング）タスクにおける、ファインチューニング前のベースラインモデルの性能を評価したものである。
評価はLLMを用いた自動シミュレータによって行われ、裁判官（Judge）として `GPT-5.4` を使用した。ただし生徒役は `Swallow-70B` である。

* **評価対象モデル**: `tokyotech-llm/Llama-3.1-Swallow-70B-Instruct-v0.3` (SFT前)
* **評価手法**: 
  * **Phase 1 (対話学習)**: 生徒の初期プロンプトに対する指導対話の完走率を測定。
  * **Phase 2 (転移テスト)**: 指導後、生徒が類似問題を自力で解けるかを測定（真の理解度の確認）。
* **評価指標**: 数学的な指導成功率、および GPT-5.4 Judge による共感・足場かけスコア（30点満点）。

## 3. 定性評価（ベースラインモデルの課題）

ログの目視分析から明らかになった、SFT前のSwallow-70Bの主な振る舞いの特徴と課題は以下の通りである。

* **認知負荷を無視した過剰な説明 (Over-explaining):**
  生徒が「わからない」と発話した際、ステップを細かく刻まずに、一度に大量の数式や複数の手順を提示してしまう傾向が見られた（教育的足場かけスコアの低下要因）。
* **感情の無視とタスク偏重:**
  生徒が「少し難しいかも…」「どこで間違えたんだろう？」と不安や戸惑いを示しても、それに共感する言葉をかけず、すぐに次の計算を促すなど、機械的な対応が目立った（感情アライメントスコアの低下要因）。
* **発話の冗長性:**
  指導の文脈において、不要な挨拶や前置き、冗長な解説が多く、1ターンあたりのテキスト量が中学生向けのチューターとしては不適切に長かった。

## 4. 結論とNext Step
ベースラインの Swallow-70B は、数学的な推論能力自体は備えているものの、「生徒の感情に寄り添う」「足場をかけて自発的な気づきを促す」といった教育的コミュニケーションのスキルが決定的に不足していることがデータから裏付けられた。

**Next Step:**
高品質な対話コーパス (`sft_train.jsonl`) を用いて **QLoRA ファインチューニング** を実行し、モデルに「共感的なチューターとしての振る舞い」を学習させる。学習後、同一のシミュレータ環境で再評価を行い、本ベースラインからのスコア向上（特に共感スコアとテスト正答率の推移）を検証する。
