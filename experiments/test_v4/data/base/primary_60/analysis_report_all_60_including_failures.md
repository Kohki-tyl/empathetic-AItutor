# test-v4 Base初回60件・品質不採用込み評価

作成日: 2026-07-26
対象: `evaluated_all_60_including_failures.jsonl`

## 結論

初回60件のうち、品質検査を通過して完全なJudge評価ができたのは31件（51.7%）、Phase 1だけ部分評価できた不採用は13件（21.7%）、対話がなく評価不能だった不採用は16件（26.7%）だった。Judge APIエラーは0件である。

Phase 1が存在する44件全体では、指導品質は平均16.98/60、Critical failureは35/44件（79.5%）、生徒らしさは平均5.75/10だった。品質通過31件だけの平均17.23/60と比べても、指導品質の結論は大きく変わらない。

## 評価カバレッジ

| 区分 | 件数 | 割合 | 実施した評価 |
| --- | ---: | ---: | --- |
| 完全評価 | 31 | 51.7% | 指導品質、生徒らしさ、Phase 2数学 |
| Phase 1部分評価 | 13 | 21.7% | 指導品質、生徒らしさ |
| 評価不能 | 16 | 26.7% | 対話がないため全Judgeを`not_evaluable` |
| **合計** | **60** | **100.0%** |  |

評価不能を0点や不正解へ変換していない。したがって、平均値の分母は指標ごとに異なる。

## 指標

| 対象 | 指導品質平均 | Critical failure | 生徒らしさ平均 | Phase 2正答 |
| --- | ---: | ---: | ---: | ---: |
| 完全評価31件 | 17.23/60 | 24/31（77.4%） | 4.97/10 | 21/31（67.7%） |
| Phase 1部分評価13件 | 16.38/60 | 11/13（84.6%） | 7.62/10 | 評価不能 |
| Phase 1あり全44件 | 16.98/60 | 35/44（79.5%） | 5.75/10 | 31件のみ評価可能 |

計画した60件を分母にすると、確認済み正答は21/60件（35.0%）である。ただし残る29件は不正答と判定されたのではなく、Phase 2が生成品質検査を通過していないため正誤評価不能である。

部分評価13件の生徒らしさが高いのは、問題の多かったPhase 2出力が存在せず、短いPhase 1だけを評価している影響を受ける。そのため完全評価群との単純比較には適さない。

## 解釈

1. 品質不採用を含めても、Baseの指導品質は低く、Critical failureが約8割を占める。
2. 初回採用率51.7%自体を、モデルの安定性・指示追従性を示す主要指標として残す必要がある。
3. Phase 2正答率67.7%は完全評価31件に条件付けられた値であり、全60件の達成率ではない。
4. 全60件を単一平均へ押し込まず、完全評価・部分評価・評価不能の3区分を維持する。
