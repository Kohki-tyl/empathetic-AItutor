# Test v2 v3-build v3 SFT分析レポート

## 概要

`tokyotech-llm/Llama-3.1-Swallow-8B-Instruct-v0.5`へ`v3_cot_sft` adapterを適用した教師モデルを50問で評価した。ログにはadapterパス`SFT_abci/LLaMA-Factory/saves/Swallow-8B/lora/v3_cot_sft`が記録されている。50件すべてでPhase 2、共感指導、数学的指導、生徒らしさのJudge評価が成功しており、生成エラーはない。

## 主要結果

| 指標 | 結果 |
| --- | ---: |
| 評価件数 | 50 |
| 指導完了率 | 54.0%（27/50） |
| 平均Phase 1ターン数 | 7.140 |
| 近接転移正答率 | 6.0%（3/50） |
| 平均理解度変化 | +0.900 |
| 平均確信度変化 | +0.303 |
| 生成エラー | 0 |

生徒モデルの内部状態ではBaseより理解度が+0.400、確信度が+0.117大きく上昇したが、近接転移正答率はBaseの12.0%から6.0%へ低下した。シミュレータ内部の状態更新を、そのまま学習成果とは解釈できない。

## 共感指導評価

| 指標 | 平均 |
| --- | ---: |
| 感情認識 | 2.620 / 10 |
| 認知的共感 | 2.480 / 10 |
| 情緒的支援 | 4.420 / 10 |
| 合計 | 9.520 / 30 |

共感合計はBaseの9.560とほぼ同じで、差は-0.040点だった。対応する50問ではv3 SFTが上回ったものが26件、同点3件、下回ったものが21件である。差の95%対応ブートストラップ区間は-1.180〜+1.080であり、今回の50件から共感指導が改善したとは判断できない。感情認識は+0.120点、認知的共感は-0.160点、情緒的支援は同点だった。

## 数学的指導評価

| 指標 | 平均 |
| --- | ---: |
| 数学的正確性 | 2.360 / 10 |
| 誤りの診断と回復 | 1.280 / 10 |
| 適応的足場かけ | 2.160 / 10 |
| 理解確認 | 1.360 / 10 |
| 認知負荷の制御 | 3.080 / 10 |
| 合計 | 10.240 / 50 |

全項目がBaseを下回った。誤答追認は136回、直接解答は28回だった。v3 SFTは直接解答を24回減らした一方、誤答追認は34回増やしている。つまり「答えを直接教えない」振る舞いは学習された可能性があるが、代わりに正誤確認の弱い問い返しや足場かけが増えたと考えられる。

対応比較では数学指導合計がBaseを上回った問題は17件、同点1件、下回った問題は32件だった。平均差は-2.860点で、95%対応ブートストラップ区間は-5.500〜-0.280だった。少なくとも今回の50件では、数学的指導の低下を単なる標本変動だけで説明するのは難しい。

## Baseとの同一条件比較

| 指標 | Base | v3 SFT | 差 |
| --- | ---: | ---: | ---: |
| 指導完了率 | 68.0% | 54.0% | -14.0ポイント |
| 近接転移正答率 | 12.0% | 6.0% | -6.0ポイント |
| 共感指導合計 | 9.560 | 9.520 | -0.040 |
| 数学的指導合計 | 13.100 | 10.240 | -2.860 |
| 生徒らしさ | 5.380 | 4.080 | -1.300 |
| 理解度変化 | +0.500 | +0.900 | +0.400 |

50件すべてで問題、seed、生徒プロフィール、初期状態が一致している。指導完了はBaseのみ完了15件、v3 SFTのみ完了8件で、近接転移はBaseのみ正答3件、v3 SFTのみ正答0件だった。指導完了率差の95%対応ブートストラップ区間は-32〜+4ポイントで0をまたぐ一方、近接転移にはv3 SFTが新たに正答へ変えた問題がなかった。

理解度変化の差は+0.400（95%区間 +0.200〜+0.620）、確信度変化の差は+0.117（+0.067〜+0.169）だった。しかし、生徒らしさと近接転移が低下しているため、この内部状態の上昇は学習成立よりも盲目的同意や不自然な状態更新を反映した可能性が高い。

## 結論

v3 SFTで確認できた明確な行動変化は、直接解答の減少である。しかし共感指導はほぼ不変で、数学的指導、生徒らしさ、指導完了率、近接転移は改善しなかった。特に、直接解答を避ける制約だけが強まり、数学的検証、誤り診断、適応的足場かけが伴っていない可能性が高い。

次のコーパスでは、非直接解答だけを採択理由にせず、各教師ターンについて「生徒の式の独立検算」「誤り箇所の特定」「現在の理解に合う一段階の支援」「次ターンで検証可能な理解確認」を同時に満たす必要がある。また、SFT後の評価では内部状態値を主要成果にせず、近接転移と人手監査を中心指標にする。
