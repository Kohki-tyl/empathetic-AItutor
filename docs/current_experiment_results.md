# 現状の実験結果まとめ

更新日: 2026-07-26

## 1. 現段階の結論

本研究では、同一のSwallow 8Bを教師基盤モデルとして、v3コーパス397対話、v3をv4仕様のSFTプロンプトへ変換したv3.1、厳格監査を行ったv4コーパス104対話によるSFTを比較した。

現時点の主要な結果は次のとおりである。

1. プロフィール更新型の旧v3-buildでは、v3 SFTにより直接解答が減少した一方、数学的指導と近接転移正答率が低下した。
2. GPT-5.4生徒を用いるtest-v5では、同じv3 SFTがBaseおよびv4 SFTより高い指導品質を示した。したがって、v3の効果方向は評価方式へ依存する。
3. v3.1はv3と同じ397対話・最終教師発話・QLoRA設定を保ち、system promptとCoT区分だけをv4化した。品質通過率と生徒らしさは上昇したが、指導品質と近接転移正答率は改善しなかった。
4. 四条件共通35問では、総合指導品質がBase 18.37、v3 SFT 35.86、v3.1 SFT 32.86、v4 SFT 19.80だった。v4はv3とv3.1を全6下位項目で下回った。
5. v4はBase比で情緒的支援と理解確認を改善したが、数学的正確性、誤り診断、認知的共感、適応的足場かけおよび近接転移正答率を改善しなかった。

したがって、v3とv4の差はSFTプロンプト形式だけでは説明できない。v4の学習対話数が104件と少ないことは有力な候補だが、コーパス内容、未完了対話の割合、損失重み、最大系列長、LoRA・最適化設定も異なるため、サンプル数だけが原因とは断定できない。

## 5. 生徒モデル変更による影響

test-v4 BaseのQwen生徒とtest-v5 BaseのGPT-5.4生徒を比較すると、初回品質通過は31/60から58/60、生徒らしさは4.97/10から7.22/10へ上昇した。

両方で初回品質を通過した共通30問では、次の差があった。

| 指標 | Qwen生徒 | GPT-5.4生徒 |
| --- | ---: | ---: |
| Phase 2正答 | 20/30 | 11/30 |
| 指導品質 | 17.03 | 17.20 |
| 生徒らしさ | 4.97 | 7.53 |
| 知識境界違反 | 38件 | 15件 |

GPT-5.4生徒は役割維持、構造適合、知識境界遵守が改善した。一方、範囲外問題で未習知識を補完せず「分からない」を維持するため、Phase 2正答率は低下した。Qwen生徒の高い正答率には、プロフィール外知識の使用が含まれていた可能性が高い。

## 6. test-v4・v5の早期完了問題

Base教師は同じcheckpointであるにもかかわらず、test-v2/v3とtest-v4以降で対話長が大きく異なる。

| 条件 | 平均ターン | 1ターン終了 | 完了 |
| --- | ---: | ---: | ---: |
| test-v2/v3 Base | 6.52 | 0/50 | 34/50 |
| test-v4 Base・初回 | 1.10 | 28/31 | 31/31 |
| test-v4 Base・retry後 | 1.20 | 42/46 | 46/46 |
| test-v5 Base | 1.07 | 55/58 | 58/58 |

test-v4以降では、教師出力に`[指導完了]`が含まれた場合、その妥当性を検査せず直ちにPhase 1を終了する。JudgeによるBaseの理解確認・完了判定はtest-v4 retryで1.24/10にすぎず、46件中21件が0点だった。このため、短い対話は効率的な指導ではなく、早すぎる完了判定を主に反映している。

test-v4・v5のBase対SFT比較では、Baseが誤りを起こす前に1ターンで終了する一方、SFTは複数ターン継続して累積的な失敗機会が増える。この終了条件を修正するまで、対話長、完了率、対話全体のCritical failure率には交絡が残る。

## 7. 研究課題に対して現時点で言えること

### 認知的共感は改善したか

評価方式を越えた一貫した改善は確認できない。プロフィール更新型v3-buildでは2.640から2.480へ低下した一方、test-v5共通35問ではBase 3.60、v3 SFT 6.66、v3.1 SFT 5.74、v4 SFT 3.37だった。同じv3 SFTでも結果方向が逆になるため、生徒モデル、プロンプト、転移方式、品質通過ゲートへの依存が大きい。v4はBase比で情緒的支援を改善したが、認知的共感は改善していない。

### 数学的指導は改善したか

評価方式によって異なる。旧v3-buildではv3 SFTの数学的指導が低下したが、test-v5共通35問ではv3とv3.1がBaseより高かった。一方、v4は数学的正確性、誤り診断、足場かけのすべてでv3・v3.1を下回った。したがって、v4の厳格監査による数学的指導改善は確認できない。

### 学習成果は改善したか

一貫した改善は確認できない。v2・旧v3-buildでは近接転移正答率がBaseを下回った。test-v5共通35問ではBase 19問、v3 21問、v3.1 20問、v4 18問であり、差は小さい。Base対v4の同一49問では18対18で変化しなかった。指導品質の差が近接転移へ安定して接続していない。

### v4コーパスは有効だったか

Base比では情緒的支援、理解確認、対話継続という一部の行動変化が確認できた。しかし、同一test-v5条件ではv3・v3.1より総合指導品質と6下位項目が低く、近接転移も改善しなかった。LLM Judge上55.62/60の高品質コーパス評価が、SFT後性能を保証しなかったことになる。

v3.1によってプロンプト形式だけの影響は小さいことが示されたため、残る候補はデータ数397対104、コーパス内容、未完了対話の割合、分析損失0.25、系列長とLoRA・最適化設定である。これらを分離する実験が必要である。

## 8. 次に必要な検証

1. v3から同じ104対話を複数seedで抽出し、v4と同一の学習設定でSFTして、データ数を揃えたコーパス差を測る。
2. v4を397対話まで新規生成し、104対397の比較によってv4内のデータ数効果を測る。単純な複製による水増しは行わない。
3. 固定epoch条件と、総optimizer step・学習トークン数を揃えた条件の両方を実施し、データ数と更新量を分離する。
4. `[指導完了]`の文字列検出を廃止し、構造化された完了フラグと決定的な完了ゲートを導入する。
5. 全60問の生成失敗を失敗として含む主要解析と、共通品質通過集合による条件付き解析を併記する。
6. 1・3・5ターンまでの固定長評価を行い、長い対話ほど失敗機会が増える影響を分離する。
7. 教師ターン当たりの誤答追認、直接解答、数学的誤りを報告する。
8. frontierとone-step-beyondを人手監査し、認知状態推定、数学的検証、支援選択の失敗を分類する。
9. 複数Judgeまたは人手評価を導入し、コーパスJudgeと評価Judgeの自己整合による過大評価を検証する。

## 9. 総括

これまでの実験は、SFTが教師役LLMの表面的な応答方略を変えられることを示した。一方、答えを直接教えないこと、対話を長く続けること、感情へ言及することだけでは、認知的共感や学習成果は改善しない。必要なのは、生徒の最新発話を数学的に検証し、正しい部分と誤り原因を分離し、その診断に対応する一段階の支援を提示し、生徒自身の説明によって完了を確認する一連の精度である。

現時点の最も妥当な主張は、次のとおりである。

> SFTは直接解答、対話継続、情緒的支援、理解確認などの教師行動を変化させる。test-v5ではv3とv3.1が高い指導品質を示したが、旧v3-buildでは再現せず、近接転移の改善も一貫しない。v4はBase比で一部行動を改善したものの、同一条件ではv3・v3.1を下回った。v3.1の結果からプロンプト形式だけでは差を説明できず、データ数、コーパス内容、損失・学習設定、対話長、品質通過による選択が交絡している。
