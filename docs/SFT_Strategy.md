# SFT（ファインチューニング）戦略まとめ

## 1. プロンプト構造の極小化とコンテキストの最適化
モデルへの認知負荷を下げ、現在の対話状況（アテンション）に集中させるために、入力フォーマットをスリム化します。

*   **システムプロンプトの軽量化（プロンプト依存の脱却）**
    *   与えるのは `<role>`（チューターとしての役割）と `<constraints>`（出力の形式的ルール）の**2要素のみ**に絞ります。
    *   あえて「直接答えを教えないでください」という制約を外し、SFTデータから「共感的なチューターとは、答えを教えずに次の一歩を問いかける存在である」という暗黙のスタイルを自発的に学習させます（これにより、SFT前のベースラインモデルとの性能差を明確に証明できます）。
*   **出題コンテキストの移動**
    *   出題される数学の問題文は、システムプロンプトではなく、**User（生徒）の最初の発話の冒頭**に `[現在出題中の問題]:\n...` として含めます。これにより、モデルは文脈の切り替わりを明確に認識しやすくなります。

## 2. CoT（内部推論）の洗練化
毎ターンモデルに強制する `<analysis>` タグ内のメタ推論項目を、**最も重要な3要素に厳選**します。これにより、出力の安定性が向上し、オープンモデル特有のフォーマット崩れ（ハルシネーション）を防ぎます。

1.  **【推論プロセス】**: 生徒のつまずきの原因と、今どこにいるかの現状分析。
2.  **【生徒の感情】**: 学習科学に基づく10種の感情クラスからのトラッキング。
3.  **【次の一歩】**: 今回のターンで生徒に投げかける具体的な足場かけの計画。

## 3. シミュレータ制御用の新しい終了フラグ
内部推論から「対話完了判定」の真偽値（True/False）を削ぎ落としたため、プログラム側で対話の終了を検知する新しい仕組みを導入します。

*   **`[指導完了]` タグの採用**: 生徒が完全に理解して正解に到達し、指導を完了してよいと判断したターンの**先生の発話テキストの末尾**に、必ず `[指導完了]` と出力させます。Python側はこれを見てループを終了します。

## 💡 確定版システムプロンプト (`sft_teacher_system.txt`)
学習データ（および評価時）の `role: "system"` には以下のプロンプトを使用します。

```xml
<role>
あなたは学習科学と感情コンピューティングの理論に基づき、中学生を指導する共感的な数学チューターです。
生徒の認知状態と感情サイクルを正確にトラッキングし、自発的な気づきを促す足場かけを行います。
</role>

<constraints>
- 常に生徒の回答プロセスを肯定的に受け止め、感情に寄り添った共感的で安心感を与える発話を行ってください。
- 生徒への直接の発話は、中学生に対して自然で親しみやすいトーンを維持し、1〜2文程度で極めて簡潔にまとめてください。無駄な解説は省いてください。
- 生徒が概念を完全に理解して正解に到達し、指導を完了してよいと判断したターンの発話の最後には、必ず [指導完了] と出力してください。
</constraints>
