## 結論

v4 SFT教師の初回60件では、生成品質検査を通過したのは21件（35.0%）だった。採用21件内のPhase 2最終解答一致率は85.7%（18/21）と高いが、全60問を分母にした確認済み正答は18/60件（30.0%）である。不採用39件は不正答ではなく評価不能であり、この2つの率を区別する必要がある。

採用21件の指導品質は平均18.29/60、中央値8/60で、16件（76.2%）がCritical failureだった。正答18件のうち13件がCritical failureを伴い、正答・Critical failureなし・知識境界違反なしをすべて満たしたのは3件だけである。したがって、85.7%という最終解答一致率を、そのまま高品質な指導や妥当な知識転移の達成率とは解釈できない。

Base初回採用分と比べると、Phase 1は平均1.10ターンから4.33ターンへ長くなり、理解確認・完了判定は1.00/10から3.52/10へ改善した。一方、初回採用率は51.7%から35.0%へ低下し、不要な直接解答は合計2件から17件へ増えた。v4 SFTは対話を継続する傾向を獲得したが、数学的正確性、過剰な解答提示、生成時のプロフィール・状態制約への追従が主な課題である。

## 解釈上の制約

1. 完全Judgeは初回採用21件だけであり、不採用39件を含む全60件の指導品質平均ではない。
2. 採用分正答率85.7%には強い生成選別があり、全60問で確認できた正答は30.0%である。
3. scope別件数は3～8件と小さく、率の差を一般化できない。
4. 数学Judgeの正答は最終解答の一致であり、導出や知識源の妥当性を保証しない。
5. Baseとの各採用集合比較は問題構成が異なる。より妥当なのは共通16問の対応比較だが、これも小標本である。
6. LLM Judgeによる評価であり、人手監査との一致率は未測定である。
7. 対象は`v4-sft-provisional`であり、正式なモデル名やcheckpointを変更した結果へ自動的に一般化できない。

## 改善優先順位

1. 教師発話を出す前に計算・式変形を独立検算し、生徒の正答を誤答扱いする逆方向の誤診断を防ぐ。
2. 生徒が明示的に完成解答を求めた場合を除き、次の一歩だけを示して再回答を待つ。
3. 長い対話そのものではなく、生徒による説明・検算・類題適用を完了条件にする。
4. Phase 1・Phase 2の知識源表現をプロフィールの正規化済み知識IDへ拘束する。
5. 感情とconfidenceの更新を決定的な状態遷移関数で検証し、初回採用率低下を抑える。
6. 報告時は「正答かつCritical failureなし」「正答かつ知識境界違反なし」「3条件すべて合格」を併記する。
7. retry後は初回採用21件と新規採用分を分離し、Baseとの共通問題対応比較を再計算する。
