# 旧500対話コーパスのresearch評価

## 結論

500対話はすべて形式検査とJudge評価に成功した。researchの厳格なSFT採択基準を満たしたのは350件（70.0%）で、150件（30.0%）は不採択だった。全体得点は平均52.32/60、中央値58/60である。一方、重大失敗は83対話（16.6%）にあり、コーパスを無修正で一括採用することは推奨しない。

## 主要結果

| 指標 | 結果 |
| --- | ---: |
| 評価予定 / 評価成功 | 500 / 500 |
| 全体得点 平均 / 中央値 | 52.32 / 58.00 |
| 全体得点 最小 / 最大 | 9 / 60 |
| 適用可能な全軸8点以上 | 366件（73.2%） |
| 数学的正確性10点 | 382件（76.4%） |
| 重大失敗なし | 417件（83.4%） |
| research厳格採択 | 350件（70.0%） |
| 指導完了と判定 | 354件（70.8%） |

厳格採択は、数学的正確性10点、適用可能な全軸8点以上、重大失敗なしをすべて満たすこととして算出した。元データにはresearch形式の修正指示フィールドがないため、「未解決の修正指示なし」はこの集計では直接検証していない。

## 重大失敗

重大失敗は83対話にあり、詳細レコードは合計171件だった。同一対話に複数の失敗が記録されるため、詳細件数は対話数を上回る。Judgeの自由記述カテゴリを意味でまとめると、主な内容は次のとおりである。

- 未解決の誤りを残した完了・終結: 60件
- 生徒の数学的誤答を正答として確定: 58件
- 教師自身による重大な数学的誤り・誤概念: 49件
- 生徒の正しい推論を誤りと断定して誤修正: 3件
- 誤った式を訂正せず、その式を用いた解法へ誘導: 1件

## 旧評価との差

旧評価のrecommendationとresearch厳格採択を突合すると、旧keep 429件のうち330件が採択、99件が不採択だった。旧review 30件では11件採択・19件不採択、旧reject 41件では9件採択・32件不採択だった。旧評価とresearch評価は軸・NA・完了基準・重大失敗定義が異なるため、旧total scoreとの数値比較は行わない。

## 解釈

これは収録済み500対話の全数監査であり、生成前の失敗率や実在学習者への効果を示すものではない。Judgeには問題、参照解答、可視対話だけを渡し、生徒プロフィール、教師内部思考、旧評価結果は渡していない。近接転移評価は実施していない。
