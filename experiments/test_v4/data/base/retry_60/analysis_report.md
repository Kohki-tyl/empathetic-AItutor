## 結論

失敗分限定リトライにより、品質通過は初回31/60件（51.7%）から46/60件（76.7%）へ25.0ポイント改善した。確認済みのPhase 2正答も21/60件（35.0%）から33/60件（55.0%）へ増加した。

新規採用15件のPhase 2正答率は80.0%（12/15）だったが、10/15件（66.7%）はCritical failure、12/15件の正答の多くにも知識境界違反が見られた。最終解答の一致と、有効な指導・妥当な知識転移は分けて扱う必要がある。

## 解釈上の制約

1. retry_60は品質検査に通るまで再生成した結果であり、単発生成時の安定性を表さない。
2. 試行回数が多い行ほど生成選別を受けており、初回結果との単純な平均比較には選択効果がある。
3. Phase 2数学Judgeは最終解答の一致を主に評価し、導出や知識源の妥当性を保証しない。
4. 不採用14件を0点化しておらず、指標ごとに評価可能な分母が異なる。
5. 本レポートはBase単独であり、v4 SFTとの優劣は同一問題・同一評価区分による対応比較後に判断する。

## 推奨する報告方法

1. 初回採用率51.7%と再試行後通過率76.7%を別々に報告する。
2. 初回採用31件、再試行新規採用15件、最終不採用14件を分離する。
3. 正答率に加え、「正答かつCritical failureなし」「正答かつ知識境界違反なし」を併記する。
4. v4 SFT比較では、両条件の初回共通採用問題と、再試行後共通採用問題を別に対応比較する。
