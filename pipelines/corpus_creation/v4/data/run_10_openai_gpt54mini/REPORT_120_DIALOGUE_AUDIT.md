# v4 OpenAI生徒120対話：生成・対話全体監査レポート

## 実行概要

- 生徒モデル：`gpt-5.4-mini`、reasoning effort `none`
- 教師・監査モデル：`gpt-5.6-terra`、reasoning effort `high`
- 生成対象：`v4-0000`〜`v4-0119`
- 生成成功：120 / 120件
- 欠番・重複・残存生成エラー：0件
- 範囲関係：`mastered`、`frontier`、`one_step_beyond`、`far_beyond`を各30件
- 教師が完了と判定した対話：75件（62.5%）
- 未完了対話：45件（37.5%）

Batch API用ファイルのアップロードは、異なるrequest IDで2回ともHTTP 500となった。このため、指定方針に従い、教師ターンごとの最終監査を行わず、1対話を1リクエストとする通常Chat Completionsの対話全体監査へ切り替えた。120件すべての監査に成功し、監査エラーは0件だった。

## 当初の厳格採択結果

| 分類 | 件数 | 割合 |

| Keep | 63 | 52.5% |

この分類は、最終解・検算・理由説明へ到達しないことも非Keep理由に含めた当初基準である。

完了状態との関係は、Keepが完了54件・未完了9件、Repairが完了12件・未完了28件、Rejectが完了9件・未完了8件だった。未完了であること自体はReject理由にしておらず、その時点までの支援が高品質ならKeepとしている。

## 次期SFT方針による再分類

次のSFTでは共感タスクと数学的指導タスクの両方の精度向上を目標とする。高難度問題に対して正確かつ共感的な支援を継続する行動を学習するため、次の理由だけで非Keepとなった18対話をKeepへ変更した。

1. 10ターン以内に最終解、検算、生徒自身による理由説明へ到達しない。
2. 高難度問題で正確かつ共感的な足場を細かく提示し、問題全体へ戻る前に上限へ到達する。

| 分類 | 件数 | 割合 |
| --- | ---: | ---: |
| Keep | 81 | 67.5% |
| Repair | 24 | 20.0% |
| Reject | 15 | 12.5% |

当初のRepairから16件、Rejectから2件をKeepへ変更した。数学的誤り、誤答判定、根拠不足、プロフィール外の表面発話、制御文字、局所的にも前進しない支援不全は昇格させていない。元の監査結果は`dialogue_audits.jsonl`へ保持し、次期SFT用の有効分類は`dialogue_audits_sft_policy.jsonl`へ分離した。

## 生徒メタデータの扱い

教師SFTへ直接含まれない`knowledge_used`、`active_misconception`、`acquired_knowledge`、内部理解度などの不整合は、`metadata_warnings`へ分離し、それだけでは非Keepにしていない。

- メタデータ警告のある対話：116 / 120件（96.7%）
- メタデータ警告：合計315件

警告の大半は、教師が導入した知識が`acquired_knowledge`へ反映されない、表面上は前進しているのに理解度や誤概念が固定される、`knowledge_used`が過不足を含む、という内容だった。これは教師SFTの直接的な汚染ではないため採択から切り離したが、生徒シミュレータの心理状態推定に利用するには信頼性が不足している。

一方、未習公式を初回発話で使用する、年齢・学習範囲に対して不自然に専門的な説明をする、初回で最終解まで解くなど、表面発話に現れる「賢すぎる生徒」は採択上の問題として残した。これは10対話で検出され、教師SFTの入力文脈そのものを不自然にするため、内部メタデータ警告とは分けて扱っている。

## 非Keepの主因

1. 10ターン以内に最終解、検算、生徒自身による理由説明へ到達しない。
2. 高難度問題で足場を細かくしすぎ、問題全体へ戻る前に上限へ到達する。
3. 生徒の表面発話がプロフィール外の公式・解法・専門語を使用する。
4. 教師説明の局所的な数学的誤り、必要条件だけでの完了、理由を未確認のままの完了判定。
5. 生徒または教師発話へのNUL、ESC、バックスペースなどの制御文字混入。
6. 初期感情ラベルと初回発話の語調が一致しない。

## 総合評価

生徒をOpenAI APIへ変更した結果、120候補すべてを構造検証済み対話として生成できた。共感指導は認知的共感9.133、情緒的支援8.442であり、SFTによる共感能力向上を狙う教師例として概ね高品質である。

当初基準のKeep率は52.5%だったが、次期SFT方針では81件、67.5%をKeepとする。残る24件のRepairは、未完了そのものではなく、数学的説明、誤答判定、根拠、局所的な支援変更、出力品質などに修正が必要な対話である。15件のRejectは、表面生徒発話の知識境界違反、制御文字破損、教師だけでは直せない文脈不整合などを含むため、そのまま教師SFTへ入れない。
