# v3コーパス・ターン監査結果

## 実行結果

既存500対話に含まれる2,351教師ターンを、20点満点の基準で監査した。全ターンで監査APIの構造化出力を正常に取得した。

| 初回分類 | 件数 | 割合 |
| --- | ---: | ---: |
| Keep | 2,056 | 87.5% |
| Repair | 253 | 10.8% |
| Reject | 42 | 1.8% |
| Keep＋Repair | 2,309 | 98.2% |

割合の分母は監査に成功した2,351教師ターンである。

## 平均スコア

| 項目 | 平均 | 満点 |
| --- | ---: | ---: |
| 数学的正確性 | 3.782 | 4 |
| 生徒回答の評価 | 2.897 | 3 |
| 認知的共感 | 2.930 | 3 |
| 感情認識・情緒的支援 | 1.921 | 2 |
| 足場かけ | 2.823 | 3 |
| 対話制御 | 1.981 | 2 |
| 理解確認・完了判定 | 2.579 | 3 |
| 合計 | 18.912 | 20 |

スコア平均は高いが、重大項目は合計点で相殺せずハード条件によってRepairへ分類した。その結果、critical failureは127ターン、誤答追認は45ターン、不必要な直接解答は5ターン、現在ターンだけでは修正不能と判定されたものは16ターンだった。

## Repair結果

Repair 253ターンについて教師ターンを再生成し、同じ基準で再監査した。

| 修正後判定 | 件数 | Repair内割合 |
| --- | ---: | ---: |
| Keep到達 | 215 | 85.0% |
| 再度Repair | 29 | 11.5% |
| Reject | 9 | 3.6% |

修正後にKeepへ到達しなかった38ターンは採用しなかった。

## v3コーパス

| 項目 | 件数 |
| --- | ---: |
| 入力対話 | 500 |
| 採用対話 | 452 |
| 除外対話 | 48 |
| 採用対話中の完了対話 | 397 |
| 修正を含む採用対話 | 105 |
| 採用対話内の修正ターン | 131 |

初回Reject、修正失敗、または同一対話内の別ターンの不合格によって48対話を除外した。修正後にKeepとなった215ターンのうち、Rejectを含む別ターンと同じ対話に属するものなどは最終コーパスへ入らないため、採用対話内の修正ターンは131件である。

## v3 SFT用データ

採用対話のうち`is_completed=true`である397件を、単一のSFT用JSONLへ変換した。

| データ | 件数 |
| --- | ---: |
| v3 CoT SFT用データ | 397 |

CoT教師信号には、認知状態、感情状態、監査で検算した数学的検証、次の一歩、生徒向け最終発話を含める。train／validation分割はコーパス作成時には行わず、ABCI上のSFT設定で実施する。

## 注意点

今回の分類と修正はLLM Judgeによる自動監査であり、人手による正解保証ではない。特にcritical failure、誤答追認、修正済みターンから層化抽出して人手確認し、Judgeの偽陰性・偽陽性を測定してからv3 SFTを実行することが望ましい。
