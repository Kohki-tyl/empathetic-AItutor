# コーパスおよび教師モデルの評価設計

## 1. 目的

本研究では、数学対話コーパスと、そのコーパスで学習した教師LLMを、共通の6評価軸で評価する。評価対象は一貫して**教師の指導行動**であり、生徒LLM自体の能力、自然さ、知識境界の遵守度は評価しない。

評価は次の2群から構成する。

- **指導評価**：数学的正確性、誤り診断と回復、指導完了判定
- **共感評価**：足場かけ、情緒的支援、感情把握

教師モデルの主要評価項目は、対話生成成功率と6軸から算出する全体得点とする。6軸それぞれの得点と、指導評価・共感評価の群別結果も内訳として必ず報告し、全体得点だけで結果を解釈しない。教師との対話後に生徒LLMが類似問題へ正答できるかは、近接転移を表す**副評価**として扱う。

## 2. 評価対象と非評価対象

### 2.1 評価対象

| 対象 | 評価単位 | 評価内容 |
| --- | --- | --- |
| コーパス | 対話全体 | SFT正例として、生徒へ提示された教師発話が対話全体を通して6軸の要件を満たすか |
| 教師モデル | 未見問題における対話全体 | 固定した条件下で、生徒へ提示された教師発話が対話全体を通して6軸の指導行動を再現できるか |
| 近接転移 | 類似問題への最終回答 | 教師との対話後に、元問題と解法構造を共有する問題へ正答したか |

### 2.2 非評価対象

次の項目は、生徒LLMの品質評価として採点しない。

- 生徒らしさ、発話の自然さ、役割らしさ
- プロファイルへの完全な忠実性
- 知識境界違反の有無
- 状態更新の自然さや一貫性
- 教師の説明への同意傾向
- 生徒LLM単体の数学能力

知識境界違反が観察されても、ケースを除外したり教師の得点を下げたりしない。教師は、その時点で実際に観察できる生徒発話に対して適切に応答できたかで評価する。ただし、APIエラー、空応答、スキーマ破損など、対話を継続できない事象は評価環境の欠測として記録する。

## 3. 共通評価尺度

各評価軸を0〜10点の整数で採点する。点数は順序尺度として扱い、評価者には軸別の根拠記述を必須とする。下表の偶数点を基本アンカーとし、その中間に位置する場合だけ奇数点を用いる。

| 点 | 共通アンカー |
| ---: | --- |
| 10 | 要件を一貫して満たし、明確な問題がない |
| 8 | おおむね満たすが、軽微な不足がある |
| 6 | 要件を部分的に満たすが、教育上無視できない不足がある |
| 4 | 不足が大きく、指導効果を明確に弱めている |
| 2 | ほとんど満たさず、指導を妨げている |
| 0 | 評価軸の要件をまったく満たしていない |

評価単位は対話全体だけとし、ターン単位の得点は付与しない。評価者は、生徒へ実際に提示された教師の発話内容だけを評価し、教師の内部推論、思考過程、非表示の判断記録、停止理由、完了フラグなどの実行メタデータは採点に使用しない。問題と参照解答は数学的検算のために渡すが、生徒プロファイルと初期状態も評価入力から除外する。各軸について、根拠となる生徒発話と教師発話の位置を示し、対話全体としての採点理由を記録する。該当する機会がない軸は採点記録上 `NA` とし、軸別の有効件数を報告する。

平均点と群別平均を計算するときは、各 `NA` を分子・分母の両方から除外し、0点や中間値へ置換しない。全6軸が適用可能な対話の全体得点は6軸の単純合計とする。`NA` がある対話の全体得点は、適用可能な軸の平均を6倍して60点満点へ換算する。集計値とともに、対話ごとの適用可能軸数および軸別`NA`率を必ず報告する。

### 3.1 `NA` の判定

`NA` は、教師の応答が不十分だった場合ではなく、対話中にその軸を評価できる機会が存在しなかった場合だけに用いる。評価機会があったにもかかわらず教師が対応しなかった場合は、`NA` ではなくルーブリックに従って採点する。

| 評価軸 | `NA` になりうる対話 | `NA` にしてはいけない例 |
| --- | --- | --- |
| 数学的正確性 | 原則としてなし。評価可能な教師発話がない場合は対話生成失敗として扱う | 教師が検算しない、誤った説明をする、正誤判定を避ける |
| 誤り診断と回復 | 生徒が最初から最後まで正しく、誤り・不確実性・不完全な推論が一度もない | 誤りを見落とす、正答を誤り扱いする、回復支援を行わない |
| 指導完了判定 | 原則としてなし。完了だけでなく、継続が必要という判断も評価する | 未解決のまま完了する、理解済みなのに不必要に継続する |
| 足場かけ | 生徒が初回から十分な根拠を伴って自力完答し、追加支援が不要 | 支援が必要なのに行わない、不要なヒントや完成解答を提示する |
| 情緒的支援 | 感情・困難感・負担を示す手がかりがなく、教師も感情的介入を行わない | 明確な不安や苛立ちを無視する、感情表出がないのに過剰に慰める |
| 感情把握 | 発話が短すぎるなど、感情または中立状態を判断できる手がかりがない | 明確な感情サインを見落とす、根拠なく感情を決めつける |

教師または生徒のAPIエラー、空応答、形式破損によって評価できない場合は、軸の `NA` ではなく対話単位の生成失敗または欠測として扱う。`NA` の多い対話は高品質を意味しないため、モデル・コーパスごとに軸別`NA`率と評価機会の分布を報告する。

## 4. 指導評価

### 4.1 数学的正確性

教師が、生徒の式・計算・定義・推論・結論を正しく検証し、自身も数学的に正しい情報を提示しているかを評価する。

| 点 | 判定基準 |
| ---: | --- |
| 10 | 主要な数式と推論を検算し、正誤判定、説明、結論がすべて正確 |
| 8 | 結論と主要推論は正確だが、説明の省略または軽微な曖昧さがある |
| 6 | 中心的な方針は妥当だが、局所的な誤りまたは未検証の断定がある |
| 4 | 正しい内容と誤った内容が混在し、解決過程へ明確な悪影響がある |
| 2 | 正誤判定または主要推論に大きな誤りがあり、解決を妨げている |
| 0 | 数学的内容が全面的に不正確で、妥当な指導として利用できない |

採点時には参照解答をそのまま信頼せず、評価者が独立に問題を解き、教師と生徒の主要な式を検算する。

### 4.2 誤り診断と回復

教師が、生徒の正答、部分正答、計算ミス、手続き上の誤り、概念的誤り、単なる説明不足を区別し、誤りの原因に対応した支援によって回復へ導いたかを評価する。

| 点 | 判定基準 |
| ---: | --- |
| 10 | 正しい部分と誤りの位置・種類を特定し、原因に合う支援で生徒自身の修正へつなげる |
| 8 | 診断と回復方針は妥当だが、原因の特定または修正確認に軽微な不足がある |
| 6 | 誤りには気づくが、診断が浅い、または一般的な支援にとどまる |
| 4 | 誤りの一部だけを捉え、支援の反復やずれによって回復が不十分 |
| 2 | 誤りの位置・種類を大きく取り違え、回復にほとんど結びつかない |
| 0 | 診断と回復の試みがなく、誤りを放置している |

生徒が初めから正答しており診断機会がない場合は、正答を正しく確認できたかを数学的正確性で評価し、本軸は `NA` とする。

### 4.3 指導完了判定

教師が、正答の提示だけでなく、生徒自身の理解を示す根拠を確認したうえで、継続・完了を適切に判断したかを評価する。

完了の根拠は、少なくとも次のいずれかとする。

- 生徒が主要な途中式を自力で提示した
- 生徒が解法の理由を自分の言葉で説明した
- 生徒が誤りを修正し、同じ誤りを含まない形で解き直した
- 短い確認問題により、対象概念の理解を示した

| 点 | 判定基準 |
| ---: | --- |
| 10 | 十分な理解根拠を確認し、適切な時点で完了または継続を判断する |
| 8 | 判断は妥当だが、確認がやや弱い、または終結がわずかに冗長 |
| 6 | 正答は確認するが、理解根拠が不十分、または継続・完了の時点にずれがある |
| 4 | 推測・同意・復唱へ依存し、完了判断を支える確認が弱い |
| 2 | 未解決部分が明確に残るのに完了する、または理解成立後も不必要に指導を続ける |
| 0 | 完了・継続の判断を行わず、指導の終結を管理していない |

最大ターン数への到達は、それ自体を教師の完了判断とはみなさない。時間切れ、教師による完了、生徒の理解成立を別々に記録する。

## 5. 共感評価

### 5.1 足場かけ

教師が、生徒の現在の理解、誤り、試行に合わせて、自力で進められる最小限の次の一歩を提示したかを評価する。本研究では、認知状態への適応を足場かけの一部として扱う。

| 点 | 判定基準 |
| ---: | --- |
| 10 | 生徒の現在地に合う一段階の支援を行い、反応に応じて支援量や方法を調整する |
| 8 | おおむね適切な支援だが、粒度・順序・支援量に軽微な不足がある |
| 6 | 関連するヒントは出すが、生徒の具体的な状態への適応が弱い |
| 4 | 支援の難易度や順序が合わず、同じ問いまたは説明を反復する |
| 2 | 生徒の状態をほぼ無視し、不要な完成解答や過大・過小な支援を行う |
| 0 | 足場として機能する支援をまったく行っていない |

完成解答の直接提示は自動的に減点しない。生徒が十分に試行した後の説明、時間制約下の要約、誤概念の安全な修正など、教育的必要性があるかを文脈に基づいて判断する。

### 5.2 情緒的支援

教師が、生徒の不安、困惑、苛立ち、落胆、過信などに対し、心理的安全性を保ちながら学習課題へ戻れる支援を行ったかを評価する。

| 点 | 判定基準 |
| ---: | --- |
| 10 | 感情を適切に受け止め、具体的な努力や進捗を認め、次の行動へ自然につなげる |
| 8 | 支援は適切だが、やや一般的、または課題への接続が弱い |
| 6 | 礼儀的・肯定的ではあるが、感情や困難への具体的対応が乏しい |
| 4 | 感情を軽視する、過度に励ます、または空疎な称賛を反復する |
| 2 | 応答が生徒へ圧力を与える、または心理的安全性を明確に弱める |
| 0 | 情緒的支援がまったくなく、対話の継続を著しく妨げる |

感情表出がない中立的な場面では、過剰な慰めを行わず、落ち着いた応答をすることが適切である。この場合、感情語の明示がなくても高得点になりうる。

### 5.3 感情把握

教師が、生徒の発話に現れた感情的手がかりを根拠に、感情の種類と強さを過不足なく把握し、その把握を応答へ反映したかを評価する。

| 点 | 判定基準 |
| ---: | --- |
| 10 | 発話上の根拠と整合する感情を適切な強さで捉え、応答へ具体的に反映する |
| 8 | おおむね妥当だが、感情の種類・強さ・応答への反映に軽微なずれがある |
| 6 | 感情への言及はあるが、根拠が弱い、曖昧、または定型的 |
| 4 | 明確な感情サインの一部を見落とす、または根拠の薄い推定を行う |
| 2 | 発話と合わない感情を断定し、応答にも不整合が現れる |
| 0 | 感情を把握する試みがなく、明確な感情サインにも反応していない |

生徒LLMの内部感情ラベルを絶対的な正解とはみなさない。採点は、観察可能な発話、対話文脈、初期条件から妥当に推定できる範囲に限定する。感情サインがない場合に中立と判断し、不要な断定を避けることも適切な感情把握に含める。

## 6. 重大失敗

次のいずれかがあれば `critical_failure = true` とする。重大失敗があっても該当軸の得点を機械的に0点へ変更せず、6軸は各ルーブリックに従って独立に採点する。重大失敗率は平均点と独立して報告する。

各重大失敗について、少なくとも次を記述する。

- 発生した教師ターンと該当発話
- 失敗の種類と具体的内容
- 生徒の理解、感情または対話進行への影響
- 後続ターンで回復したか、回復可能だったか
- 関連する評価軸

記録は `critical_failure_details` の配列とし、各要素に `turn`、`category`、`evidence`、`impact`、`recovery_status`、`related_axes` を保存する。重大失敗が複数ある場合はまとめず、失敗ごとに別要素として記録する。

- 教師が数学的誤答を正答として確定した
- 教師自身が重大な数学的誤りまたは誤概念を導入した
- 生徒の正しい推論を誤りと断定し、誤った修正を強制した
- 未解決の誤りを残したまま指導完了と判定した
- 生徒の明確な困難感情を否定、非難、嘲笑または威圧した
- 対話履歴と矛盾する支援により、指導が回復不能になった

## 7. コーパス評価

### 7.1 評価手順

1. スキーマ、必須フィールド、ターン順序、空応答、文字化けを機械検査する。
2. 問題、参照解答、可視対話だけを評価者へ渡す。生徒プロファイル、初期状態、教師の内部推論、思考過程、非表示の判断記録、停止理由、完了フラグは評価入力から除外する。
3. 生徒へ提示された全教師発話を根拠として、対話全体へ6軸の得点を1組だけ付与する。
4. 重大失敗、修正可能な問題、修正指示を記録する。
5. 修正した対話は、修正前の判定を流用せず、独立に再評価する。
6. 採択後に重複、評価セットとの問題重複、解法テンプレートの過度な集中を検査する。

### 7.2 採択基準

SFTコーパスへ採択する対話は、次をすべて満たすものとする。

- 適用可能な全軸が8点以上
- 数学的正確性が10点
- `critical_failure = false`
- 未解決の修正指示がない
- 必須スキーマと教師出力形式が正常
- 学習セットと確定評価セットの間に問題または類似問題の漏洩がない

採択判定でも `NA` を数値へ置換せず、該当軸を「適用可能な全軸が8点以上」の判定対象から除外する。

診断機会や感情表出がなく `NA` が生じる対話は、それだけで不採択にしない。ただし、コーパス全体として誤答場面、困難感情、支援変更、適切な完了判定を十分に含むよう、機会の分布を管理する。

### 7.3 コーパス全体で報告する項目

- 生成数、機械検査通過数、採択数、修正後採択数、棄却数
- 全体得点の平均、中央値、分布、および適用可能軸数
- 6軸の平均、中央値、分布、`NA`率
- 重大失敗の件数と種類
- 問題分野、難易度、初期状態、初期感情、対話長の分布
- 誤答あり、困難感情あり、支援変更あり、指導完了ありの各件数
- 完全重複、近似重複、評価セットとの漏洩件数
- 教師ターン数とトークン数

## 8. 教師モデル評価

### 8.1 固定条件

教師モデル以外の条件を固定し、同一ケースを対応比較する。

- 問題セットと類似問題セット
- 問題とプロファイルの割り当て
- 生徒LLM、システムプロンプト、生成設定、最大ターン数
- 初期状態と初期感情
- 各問題・プロファイルに対応する事前生成済みの初回生徒発話
- 教師へ提示する情報と対話履歴
- 評価プロンプト、評価モデル、採点基準
- 乱数seed、再試行規則、停止条件

評価問題と分析計画はモデル結果を見る前に凍結し、学習コーパスから隔離する。比較時は、ケースの提示順だけを無作為化し、評価者には教師モデルの条件名を伏せる。

確定評価セットは、翻訳済み問題をファイル順で見た末尾200問を母集団とする。既存の品質検査で除外された18問を除き、学習状況の4区分から固定seedで各25問を選び、合計100問とする。この4区分は生徒プロファイルの初期状態に含め、生徒LLMへ渡す。選定結果、除外ID、入力ファイルのハッシュ、seedを保存し、教師モデルの結果を確認した後には変更しない。

### 8.2 主要評価項目

- **対話生成成功率**：予定した全ケースのうち、所定の形式を保ち、事前に定めた終了条件まで評価可能な対話を生成できた割合
- **全体得点**：全6軸が適用可能な場合は単純合計、`NA` がある場合は適用可能軸の平均を6倍した換算値（60点満点）

全体得点の内訳として、6軸それぞれの対話単位得点、指導評価平均、共感評価平均、重大失敗率、指導完了率、最大ターン到達率、適用可能軸数、軸別`NA`率を必ず併記する。数学的失敗が共感得点で相殺される可能性があるため、全体得点だけを単独で解釈しない。

### 8.3 生成失敗と欠測

- 教師モデルの空応答、形式破損、生成停止は教師側の失敗として記録する。
- 生徒LLMまたはAPIの一時的失敗には、事前に固定した回数だけ同一条件で再試行する。
- 生徒側の再試行後も対話不能なケースは欠測とし、教師得点へ変換しない。
- 条件ごとの予定件数、実行件数、評価可能件数、欠測理由を必ず報告する。
- 対話生成成功率は予定した全ケースを分母とし、全体得点は評価可能な対話を分母として示す。両者を統合した単一指標にはしない。

## 9. 生徒LLMの設計

### 9.1 使用モデル

生徒LLMには `gpt-5.4` を使用する。実験時には、APIへ指定したモデル名に加え、取得可能であれば解決されたスナップショット、実行日、プロンプト版、生成パラメータをmanifestへ保存する。

### 9.2 プロファイル

プロファイルに設定する内容は、次の3項目とする。

- 学年
- 話し方
- 初期状態

IDはケース対応と再現性のための識別子として保持する。計算精度、メタ認知能力、自己説明、援助要請、誤り持続性などの数値・行動パラメーターは設定しない。既習内容・未習内容の一覧や対象分野ごとの習熟度も設定しない。

話し方は、学年に対応する曖昧な表現ではなく、観察可能なカテゴリで設定する。

- 口調：`タメ口` または `丁寧口調`
- 自信の表し方：`自信がある`、`慎重`、`控えめ`
- 発話量：`短い` または `標準`

自信の表し方は言語表現の傾向に限り、数学能力、正答率、理解度、計算精度を意味しない。初期感情と衝突する場合は、口調を維持しつつ、その時点の感情をためらい、確認表現、発話量などへ反映する。

プロファイルは生徒を採点するためではなく、教師へ異なる指導条件を与える実験操作として用いる。

### 9.3 初期状態の決定

初期状態はケースごとに、次の4項目で構成し、生徒プロファイルの中に含める。

- 学習状況：`mastered`、`frontier`、`one_step_beyond`、`far_beyond` の4区分
- 初期感情
- 初期感情の理由
- 事前生成して固定した初期応答

4区分は統合せず、そのまま維持する。分野別習熟度は設定しない。同一問題を複数モデルで比較する場合、これらの初期状態を完全に固定する。

学習状況と初期感情には意図的な相関を持たせる。習得済みに近い状態では中立・意欲・好奇心を、学習範囲から離れるほど混乱・不安・苛立ちを生じやすくする。これは現実的な学習場面を構成するための複合シナリオであり、学習状況と感情の独立した因果効果を推定する設計ではない。結果では両者を独立要因として解釈せず、必要に応じて複合シナリオ別の記述統計として示す。

### 9.4 初回生徒発話の事前生成

問題、簡易プロファイル、学習状況、初期感情と理由を確定した後、各ケースの初期応答を `gpt-5.4` で一度だけ事前生成する。生成した応答は初期状態の一部として固定し、すべての教師モデル条件へ同一内容を渡す。

事前生成では次の規則を用いる。

- ケースごとに初期応答を1件採択し、ケースID、モデル名、プロンプト版、生成設定、seed、実行日、本文ハッシュを保存する。
- APIエラー、空応答、形式破損の場合だけ、事前に定めた回数まで再試行する。
- 知識境界違反、プロファイルとのずれ、数学的正誤を理由に再生成または選別しない。
- 教師モデルの評価開始後は、初期応答を変更しない。
- 2回目以降の生徒発話は、各教師モデルとの対話履歴に応じて `gpt-5.4` で生成する。

これにより、教師モデル間の比較開始点を一致させる一方、教師の介入後に生じる対話経路の違いは保持する。

### 9.5 知識境界違反の扱い

生徒LLMが初期状態から想定される範囲を超えた知識や解法を生成しても、再生成、除外、減点を行わない。これは生徒LLMの限界として受け入れ、件数だけを実行診断情報として保存できるが、主要評価・副評価には用いない。

この方針により、教師評価の分母が、生徒LLMの知識境界遵守度によって条件ごとに変わることを避ける。教師は、実際に現れた生徒発話への応答品質で評価される。

## 10. 類似問題による副評価

教師との対話終了後、元問題と解法構造を共有し、表面的な数値・文脈だけが異なる類似問題を生徒LLMへ提示する。評価は最終回答の数学的正誤に限定し、生徒の説明品質、自然さ、知識境界、プロファイル整合性は採点しない。

副評価では次を固定する。

- 類似問題の作成規則と難易度
- 元問題との解法構造の対応
- 生徒LLMへ渡すPhase 1情報
- 解答プロンプト、生成設定、採点方法
- 正規化規則と許容する同値表現

報告指標は類似問題正答率とし、教師モデル間では同一ケースの対応差を示す。この指標は、実際の人間学習者の学習効果でも、生徒LLMの恒久的な能力変化でもない。あくまで、対話履歴を与えられた生徒LLMが示す**近接転移の代理指標**として解釈する。

## 11. 評価の信頼性

- 全件をLLM Judgeで採点した後、後続工程として層化抽出した標本を人手で二重評価する。
- 層化には、教師モデル条件、初期状態、正誤、困難感情、完了・未完了、重大失敗を用いる。
- 評価者間一致は、軸別に重み付きκ係数または順序尺度向けの一致指標を報告する。
- 不一致例を用いてルーブリックを修正する場合、確定評価セットの採点前に修正版を凍結する。
- コーパス生成モデル、教師モデル、評価モデルが同系統の場合は明示し、可能であれば異なる評価モデルまたは人手評価で感度分析を行う。

## 12. 統計解析と報告

- 教師モデル比較は同一の問題・プロファイルを用いた対応解析とする。
- 対話生成成功率の差と、全体得点の平均差または中央値差を主要結果として報告する。
- 全体得点と6軸それぞれについて、対応ブートストラップ95%信頼区間を報告する。
- 重大失敗率、完了率、類似問題正答率は対応する二値データとして差と信頼区間を報告する。
- 初期状態、問題分野、問題難易度、対話長による層別結果を示す。
- 対話長は教師モデルの影響を受ける処置後変数であるため、対話長別の結果を因果効果として解釈しない。
- 多数の軸を検定する場合は、主要評価項目を事前指定し、多重比較を考慮する。
- 有意差の有無だけでなく、効果量、信頼区間、欠測、生成失敗、評価可能分母を併記する。

サンプルサイズ、最大ターン数、生成seed数、Judge構成、人手評価件数は、予備実験の分散と利用可能な計算資源に基づいて決定し、確定評価の実行前に追記・凍結する。

## 13. 解釈上の境界

本評価から直接主張できるのは、合成された生徒LLMとの固定条件下で観察された教師LLMの指導行動である。次は直接には主張できない。

- 実在する生徒に対する学習効果
- 生徒の感情や認知状態を正確に読み取る一般能力
- 生徒LLMの内部状態またはパラメータが学習によって更新されたこと
- 類似問題正答率が長期的な知識定着を表すこと
- 特定の生徒LLMで得た結果が、別の生徒モデルや実学習者へ一般化すること

したがって、本研究の結論は「教師モデルの指導品質」と「合成対話上の近接転移代理指標」に限定して記述する。
