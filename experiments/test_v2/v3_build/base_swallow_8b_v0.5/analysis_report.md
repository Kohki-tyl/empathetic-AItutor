# Test v2 v3-build Base分析レポート

## 概要

v2_buildの200問から抽出された50問について、未SFTの`tokyotech-llm/Llama-3.1-Swallow-8B-Instruct-v0.5`を教師役とした結果である。50件すべてでPhase 2、共感指導、数学的指導、生徒らしさのJudge評価が成功しており、生成エラーはない。

## 主要結果

| 指標 | 結果 |
| --- | ---: |
| 評価件数 | 50 |
| 指導完了率 | 68.0%（34/50） |
| 平均Phase 1ターン数 | 6.520 |
| 近接転移正答率 | 12.0%（6/50） |
| 平均理解度変化 | +0.500 |
| 平均確信度変化 | +0.186 |
| 生成エラー | 0 |

指導完了率に対して近接転移正答率が低く、教師が完了と判断したことと、生徒が会話履歴なしで類似問題を解けることには大きな隔たりがある。

## 共感指導評価

| 指標 | 平均 |
| --- | ---: |
| 感情認識 | 2.500 / 10 |
| 認知的共感 | 2.640 / 10 |
| 情緒的支援 | 4.420 / 10 |
| 合計 | 9.560 / 30 |

情緒的支援は相対的に高いが、感情認識と認知的共感は3点未満である。安心させる表現は出せても、つまずきの原因や必要な支援量の推定が具体的な教師行動へ十分反映されていない。

## 数学的指導評価

| 指標 | 平均 |
| --- | ---: |
| 数学的正確性 | 2.460 / 10 |
| 誤りの診断と回復 | 2.020 / 10 |
| 適応的足場かけ | 3.240 / 10 |
| 理解確認 | 1.880 / 10 |
| 認知負荷の制御 | 3.500 / 10 |
| 合計 | 13.100 / 50 |

理解確認が最も低く、数学的正確性と誤り診断も低い。50対話で誤答追認が102回、直接解答が52回検出された。早く完了する一方、誤りの回復や定着確認が不十分な対話が含まれる。

## 生徒シミュレータ

| 指標 | 結果 |
| --- | ---: |
| 生徒らしさ | 5.380 / 10 |
| 教師役への逸脱 | 3回 |

| 発話スタイル違反 | 26回 |
| 不自然な状態更新 | 21回 |

JSONや教師の内部`<analysis>`の露出は検出されなかった。一方、教師への盲目的同意が多く、対話中の理解度変化をそのまま教育効果と解釈することはできない。

## プロフィール別結果

| プロフィール | 件数 | 完了率 | 転移正答率 | 共感合計 | 数学指導合計 | 生徒らしさ |

件数が8〜16件と少ないため、プロフィール差は傾向として扱う。V2-S01では50問中の転移正答がなく、V2-S02は完了率が高い一方で共感合計が低い。

## 更新後のv3 SFTとの対応関係

更新されたv3 SFT結果とは、50件すべてで`run_id`、問題、seed、生徒プロフィール、初期状態が一致している。このため、以前の結果にあったプロフィール割り当ての不一致は解消され、同一条件の対応比較が可能になった。

ただし、評価件数は50件であり、同一のLLM Judgeと生徒シミュレータに依存する。差の一般化には、seedを増やした追試と、人手によるターン単位監査が必要である。

## 結論

Baseは68.0%の対話を完了したが、近接転移は12.0%に留まった。主な課題は、数学的正確性、誤り診断、理解確認、誤答追認である。更新後の同一条件比較でも、教師発話が対話を終わらせること、シミュレータ内部の理解度が上がること、近接転移問題に正答することを分離して評価する必要がある。
