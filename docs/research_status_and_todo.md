### v1 SFTモデルとベースラインの評価

同じ200問を用いて、Swallow 8Bのベースラインモデルとv1 SFTモデルを評価した。

| 指標 | ベースライン | v1 SFT | 差分 |
| --- | ---: | ---: | ---: |
| 対話放棄率 | 29.5%（59/200） | 0.0%（0/200） | -29.5pt |
| 近接転移正答率 | 9.2%（13/141） | 11.5%（23/200） | +2.3pt |
| 感情認識精度 | 6.4 | 5.7 | -0.7 |
| 教育的共感（認知的共感を含む） | 4.6 | 3.9 | -0.7 |
| 対話長制御 | 6.6 | 9.0 | +2.4 |
| 共感評価総合点 | 17.6 | 18.6 | +1.0 |

近接転移正答率は、指導対話後に類似構造の新しい問題を自力で解けた割合である。ベースラインでは対話放棄59件を除く141件、v1 SFTでは全200件を分母としているため、+2.3ポイントは参考値であり、完全に同じ母集団の比較ではない。

v1 SFTにより対話放棄がなくなり、発話の簡潔さと共感評価総合点は改善した。一方、感情認識精度と教育的共感はともに0.7点低下した。

#### 感情認識と認知的共感

**感情認識精度**は、生徒の混乱、苛立ち、不安、退屈などを教師が正しく捉えられたかを表す。例えば、理解できずに困っている生徒を「意欲的」「中立」と誤認せず、混乱やフラストレーションとして認識できることを評価する。v1 SFTは5.7点で、ベースラインの6.4点を下回った。この結果から、v1 SFTは対話を継続させる形式を学習した一方、生徒の発話から感情状態を読み分ける能力までは改善できていない可能性がある。

**認知的共感**は、生徒が何を理解し、どこでつまずき、なぜその誤りに至ったかを教師が推定し、その状態に合う支援へ変換する能力である。本評価では独立した指標ではなく、心理的安全性、誤りの正常化、ヒントの細分化、思考機会の確保を測る「教育的共感」に含めて評価している。v1 SFTは3.9点で、ベースラインの4.6点を下回った。短い応答を生成する能力は向上したものの、生徒の誤概念を診断して適切な一歩を提示する内容面の改善が不足していたと考えられる。

したがってv2では、単に肯定的で短い応答を学習させるのではなく、感情の認識、誤概念の特定、正しい部分と誤りの区別、理解段階に応じた足場かけを重視する。

### コーパスの評価

500件の共感的数学対話を、感情認識、教育的共感、数学的正確性、エラー回復、適応的足場かけ、発話長の6軸で評価した。

| 評価結果 | 件数 | 割合 |
| --- | ---: | ---: |
| Keep | 429 | 85.8% |
| Keep以外 | 71 | 14.2% |

| 評価指標 | 全500件の平均 |
| --- | ---: |
| 感情認識精度 | 8.58 |
| 教育的共感（認知的共感を含む） | 8.77 |
| 数学的正確性 | 9.16 |
| 誤りの検出と回復 | 8.31 |
| 適応的足場かけ | 8.92 |
| 対話長制御 | 9.59 |
| 総合点 | 53.32 / 60 |

重大な指導上の問題は52件、誤答追認は57対話で検出された。これらを除外し、以下の条件を満たした429件からv2 SFTデータを作成した。

#### Keepの厳密な定義

Keepは、評価と指導が正常に完了し、JudgeがそのままSFTに利用可能と判定した対話である。数学的誤り、誤答の肯定、重大な指導上の問題、答えの一方的な提示、危険なデータ破損がなく、感情認識、認知的・教育的共感、誤りからの回復、適応的な足場かけを満たすことを条件とした。

今回のKeep 429件では、重大な指導上の問題と誤答追認はいずれも0件だった。条件を満たさない71件はv2 SFTから除外した。

### v2 SFTの設計

- Keep-only 429件を学習データとして使用
- 誤答を安易に肯定しない教師プロンプトへ更新
- 評価対象の教師モデルと固定生徒モデルを分離
- 生徒の理解度、誤概念、確信度、感情を状態として管理
- Phase 2には対話全文ではなく、Phase 1終了時の学習状態だけを引き継ぐ
- 生徒の教師口調、知識逸脱、文体、不自然な理解更新も評価
