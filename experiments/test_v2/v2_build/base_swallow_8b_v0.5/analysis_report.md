# Test v2 Base Swallow 8B 分析レポート

## 概要

未SFTの`tokyotech-llm/Llama-3.1-Swallow-8B-Instruct-v0.5`を教師役としたプロファイル更新テストの結果である。対話生成と4種類のJudge評価は182件で正常に記録されている。予定した200件には18件不足しているため、本レポートは完了済み182件の暫定集計である。

## 主要結果

| 指標 | 結果 |
| --- | ---: |
| 評価件数 | 182件 |
| Phase 1指導完了率 | 73.6%（134/182） |
| 平均Phase 1ターン数 | 6.082 |
| Phase 2近接転移正答率 | 14.3%（26/182） |
| 平均理解度変化（0～4） | +0.484 |
| 平均確信度変化（0～1） | +0.192 |
| 生成エラー | 0件 |

指導完了率は比較的高いが、近接転移正答率は14.3%に留まった。教師が対話を完了したと判断しても、会話履歴を除いた類似問題で知識を利用できるとは限らない。

## 共感指導評価

各下位指標は10点満点、合計は30点満点である。

| 指標 | 平均 |
| --- | ---: |
| 感情認識 | 2.758 |
| 認知的共感 | 2.819 |
| 情緒的支援 | 4.643 |
| 共感指導合計 | 10.220 / 30 |

情緒的支援は3指標の中で最も高いが、感情認識と認知的共感はいずれも3点未満である。肯定的な声かけは行えても、生徒の感情、誤概念、つまずきの原因を具体的に推定し、指導へ反映する能力が弱い。

## 数学的指導評価

各下位指標は10点満点、合計は50点満点である。

| 指標 | 平均 |
| --- | ---: |
| 数学的正確性 | 3.308 |
| 誤りの診断と回復 | 2.495 |
| 適応的足場かけ | 3.648 |
| 理解確認 | 2.154 |
| 認知負荷の制御 | 4.110 |
| 数学的指導合計 | 15.714 / 50 |

認知負荷の制御と足場かけは相対的に高い。一方、理解確認が最も低く、誤りの診断と回復も弱い。Judgeが検出した誤答追認は合計332回、直接解答の提示は172回だった。対話を早く完了させる傾向の一部は、十分な理解確認を行わずに完了判定を出している可能性がある。

## スコア例

- 指導評価合計の最高：`math_train_1036`（62/80）
- 指導評価合計の最低：`math_train_1062`（6/80）

最低例では、数学的誤りや対話の不整合を個別に確認し、誤答追認、直接解答、理解確認不足のどれが主要因かを質的に分類する必要がある。

## v2 SFTとの比較

同じ182問で比較すると、Baseはv2 SFTより、指導完了率で23.1ポイント、近接転移正答率で1.7ポイント、共感指導合計で0.813点、数学的指導合計で2.170点、生徒らしさで0.731点高かった。対応比較でも、共感合計は100問、数学指導合計は99問、生徒らしさは87問でBaseが上回った。

一方、Baseは直接解答が172回と、v2 SFTの57回より多い。Baseの高い完了率は、常により良い教育的指導を意味するわけではない。直接解答を抑えながら、数学的正確性、誤り診断、理解確認を改善することが課題である。

## 結論

Baseモデルはv2 SFTより対話を短く完了させ、Judgeによる共感・数学指導評価でも平均的に上回った。しかし、認知的共感、誤り診断、理解確認、近接転移はいずれも低く、直接解答と誤答追認も多い。したがって、Baseが教育的に十分であるとは言えず、「早く完了するが、理解の定着は弱い」条件として位置づけられる。
