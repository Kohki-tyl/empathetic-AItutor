## 結論

test-v5のBase教師・GPT-5.4生徒による初回60件では、58件（96.7%）が生成品質検査を通過した。採用58件のPhase 2最終解答一致率は37.9%（22/58）、全60問を分母にした確認済み正答は36.7%（22/60）である。

一方、指導品質は平均18.86/60、中央値15/60で、47件（81.0%）がCritical failureだった。正答22件のうちCritical failureなしは7件、さらに知識境界違反なしまで満たしたものは4件だけである。したがって、最終解答一致率だけを有効な指導・知識転移の達成率として扱うことはできない。

test-v4 Baseと比べると、GPT-5.4生徒への変更により初回採用率は51.7%から96.7%、生徒らしさは4.97/10から7.22/10へ改善した。一方、共通して採用された30問では正答が20件から11件へ減った。これは、従来のQwen生徒で見られたプロフィール外知識による正答への飛躍が抑制され、`far_beyond`で「わからない」を維持する例が増えた影響を含む。正答率低下を直ちにGPT-5.4の能力低下とは解釈せず、知識境界を守る生徒シミュレーションとして評価する必要がある。

## 最終解答と指導品質の乖離

正答22件のうち15件（68.2%）がCritical failureを伴った。正答かつCritical failureなしは7件、さらに生徒の知識境界違反なしまで要求すると4件である。

代表的な乖離は`math_train_1084`である。生徒の`2/5 × 15/8 = 3/4`は正しいが、教師は「より多く食べるのは通常ない」として正答を誤り扱いした。それでもPhase 2最終解答は正答なので、数学Judgeだけなら成功に見える。逆にfar_beyondでは、知識境界を守って「わからない」を維持した自然な生徒応答が数学Judgeでは不正答となる。

このため、転移成功の主指標には少なくとも次の3条件を併記すべきである。

1. Phase 2最終解答が正しい。
2. 教師指導にCritical failureがない。
3. 生徒の知識境界違反がない。

本データで3条件をすべて満たすのは4/58件（6.9%）、計画60問に対して4/60件（6.7%）である。

## 解釈上の制約

1. 完全Judgeは初回採用58件のみであり、不採用2件を含む全60件の平均ではない。
2. test-v4との主な変更は生徒モデルだが、API生成経路もvLLMからOpenAI Structured Outputsへ変わっているため、差をモデルだけに帰属できない。
3. 数学Judgeの正答は最終解答の一致であり、導出・知識源・教師指導の妥当性を保証しない。
4. far_beyondでの低正答率は、プロフィールを守る自然な未解決応答を含み、通常の数学ベンチマーク正答率とは意味が異なる。
5. LLM Judgeによる評価であり、人手監査との一致率は未測定である。
6. test-v4との共通30問比較でも、生徒応答が変わるため教師発話の条件が同一ではなく、教師モデル単独の固定入力比較ではない。

## 改善優先順位

1. 教師の完了判定を、生徒が途中式・言い換え・検算を実際に返した後に限定する。
2. 教師発話前に計算と式変形を独立検算し、生徒の正答を誤答扱いする逆方向の誤診断を防ぐ。
3. 生徒が明示的に完成解答を求めた場合を除き、次の一歩だけを提示して応答を待つ。
4. Phase 2で使用可能な問題条件と知識源を構造化IDで拘束し、意味的な知識源違反を追加検査する。
5. 報告時は正答率だけでなく、「正答・Critical failureなし・知識境界違反なし」の同時達成率を主指標として併記する。
6. Qwen生徒とGPT-5.4生徒の共通30問を人手監査し、正答減少が知識境界遵守によるものか、過度な能力抑制によるものかを分類する。
